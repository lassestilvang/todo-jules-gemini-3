💡 What: Added a custom equality comparator to React.memo() for the TaskItem component.
🎯 Why: Data fetched from the database in Next.js Server Components generates new object references on every route revalidation, defeating default React.memo referential equality and causing O(N) re-renders for unchanged items in the list.
📊 Impact: Prevents unnecessary O(N) DOM diffing and re-renders for unchanged TaskItems when the task list updates.
🔬 Measurement: Verify using React Developer Tools Profiler; toggling a single task will no longer trigger re-renders for all other unchanged tasks in the list.

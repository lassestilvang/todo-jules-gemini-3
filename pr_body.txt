🚨 Severity: HIGH

💡 Vulnerability: The `getTaskDetailedInfo` function in `src/actions/tasks.ts` is an exported Server Action called from a Client Component (`TaskDetailSheet`) to fetch subtasks, labels, and attachments. It was missing rate limiting, making it vulnerable to abuse.

🎯 Impact: A malicious actor could repeatedly call this read-heavy Server Action, causing database connection exhaustion and a Denial of Service (DoS) for the application.

🔧 Fix: Added the `rateLimit` check to `getTaskDetailedInfo`, restricting it to 60 requests per minute per IP, matching the established security pattern for other read-heavy actions in the codebase.

✅ Verification: Verified the fix passes TypeScript compilation, `bun run lint`, and tests.
💡 What: Added text truncation to attachment filenames and a native `title` attribute to show the full name on hover. Also prevented the file icon from squishing.
🎯 Why: Long filenames previously caused layout breakage in the constrained sidebar/sheet. While truncation fixes the layout, it hides information; the tooltip restores accessibility for the full name.
📸 Before/After: Long names now truncate cleanly with `...` and show a native tooltip on hover.
♿ Accessibility: Added a native `title` attribute to the attachment link, ensuring users can read the full filename even when truncated.
